# Повторная приёмка Windows 2026-10-31

Проверены изменения после `b44736d` в ветке `codex/windows-compatibility`.
Backend собран из текущей ESKA после Windows-исправлений; Metadata API 1.35.
Версию расширения и publication pipeline вручную не меняли.
[Машиночитаемые результаты](measurements/windows-review-2026-10-31.json).

## Окружение

Windows 11 IoT Enterprise LTSC 2024, build 26100, x64; Intel i5-6200U,
8 GiB RAM. Microsoft VS Code 1.144.0, Node 24.22.2, Bun 1.4.4,
Python 3.14, Rust 1.99.1 / MSVC 14.44. Официальный bsl-analyzer 0.4.2.
Все проекты созданы в собственных уникальных подкаталогах соседнего
`eska/../eska-playground`; пользовательские demo не изменялись.

## Найденные и исправленные ошибки

- Бюджет выравнивания подсказок проверяется до создания строк и декораций.
  Регрессия воспроизводила выделение 2 100 225 символов при лимите 131 072.
- После завершения индексации и рестарта анализатора инвалидируются подсказки.
  Ответ устаревшего запроса вызывает отложенное обновление после его кэширования
  редактором; dispose отменяет обновление.
- Холодный переход раскрывает всю цепочку предков последовательно. Ошибки
  готовности native-дерева распознаются и после передачи через RPC.
  Обновление групп сохраняет существующее выделение и учитывает удалённые узлы.
- Native-проверки сравнивают физические Windows-пути, включая `C:`/`c:`.
  Добавлен Windows-адаптер официального анализатора для наблюдения за VFS,
  отменой подготовки и завершением принадлежащих тесту дочерних процессов.

## Воспроизведение

Используются команды `bun run check`, `bun run compile`, Node test runner
с `--test-concurrency=1`, Bun с `--max-concurrency=1`, Python release tests,
`bun run package` и `scripts/check-vsix.py`.
Для native-проверок задаются абсолютные `ESKA_TEST_ROOT` (соседний playground),
`ESKA_TEST_BINARY`, `ESKA_TEST_FMT_BINARY`, `ESKA_TEST_ANALYZER_BINARY`,
`VSCODE_EXECUTABLE` и `VSCODE_CLI_JS`. Адаптер собирается командой
`rustc test/activity-analyzer.rs -o <уникальный-стенд>/activity-analyzer.exe`
и передаётся через `ESKA_HOST_ACTIVITY_ANALYZER`. Установленный пакет выбирается
через `ESKA_TEST_VSIX`; без него host использует source SDK. Русский язык
требует соответствующего language pack. `test/run-host.mjs` создаёт и удаляет
только собственный профиль, extensions directory и fixture.

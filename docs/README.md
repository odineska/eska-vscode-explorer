# Документация ESKA Explorer

[Полное руководство](https://odineska.github.io/eska/docs/) описывает текущие
пользовательские возможности ESKA и Explorer. В нём есть
[практический маршрут от EPF до обработки аудита пользователей БСП](https://odineska.github.io/eska/docs/#practice),
[все настройки и команды](https://odineska.github.io/eska/docs/#settings),
[справочник CLI](https://odineska.github.io/eska/docs/cli/) и
[все параметры форматирования](https://odineska.github.io/eska/docs/formatting/).

Планы, старые отчёты приёмки и измерения фиксируют свою дату и среду.
Они не означают, что будущая задача реализована или что конкретная ОС
проверена всеми позднейшими сценариями. Текущая приёмка Windows проходит отдельно.

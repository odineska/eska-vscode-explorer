# Растеризация подписей Linux

Этот модуль использует FreeType Project (https://freetype.org).
Выбрана FreeType Project License; полные уведомления FreeType, Emscripten,
musl и compiler-rt находятся в `NOTICES.txt` и включаются в VSIX.

`font-raster.wasm` — runtime-ресурс профиля Linux 8.3.27.2342, а не результат
запуска установленной 1С. Используются комплектные Liberation Sans 2.1.5,
FreeType 2.13.2, TrueType interpreter 40 и LCD filter DEFAULT.
Для обычных доступных кнопок без картинки/меню/явного фона берётся красный
канал LCD-покрытия, соседние глифы складываются с насыщением, затем текст
однократно смешивается с дискретным фоном кнопки. Область ограничивается
пересечением логической ширины и общих границ ink-метрик. Canvas содержит
только прямоугольник текста; рамки остаются общим CSS-компонентом.

Это не профиль текста всех элементов: подписи полей эталонного Конфигуратора
используют цветное LCD-сглаживание. Пока растеризуются только обычное и жирное
начертания Sans без подчёркивания/зачёркивания, простой Latin/Cyrillic-текст
в диапазоне 1–128 px. Неподдержанное написание, шрифт или ошибка ресурса
оставляют доступный текст браузера и показывают сообщение о неполном совпадении.
Основные, недоступные, плоские кнопки и кнопки с картинкой используют прежний
рендерер. Эти ограничения не означают завершение визуальной приёмки.

## Воспроизведение

Нужны Python 3.12+, CMake, Ninja и установленный Emscripten SDK **6.0.13**
(release `eb132757325583b787fe9414b09afea9442b72ad`). Обычная сборка расширения
использует готовый WASM и не запускает эти инструменты или скачивание.

Архив: https://download-mirror.savannah.gnu.org/releases/freetype/freetype-2.13.2.tar.xz
SHA-256: `12991c4e55c506dd7f9b765933e62fd2be2e06d421505d7950a132e4f1bb484d`.
Из корня Explorer:

```sh
python3 scripts/form-font-raster.py --emsdk /path/to/emsdk --source-archive /path/to/freetype-2.13.2.tar.xz
node --test test/form-font-raster.test.mjs
```

Скрипт проверяет версию SDK и хеш архива, собирает в собственном временном
подкаталоге соседнего `eska-playground`, удаляет его и обновляет WASM/manifest.
Собираются модули TrueType, SFNT, PS names и smooth renderer; внешние библиотеки
отключены. Отключены environment properties; шрифты открываются из памяти.
`fd_read`/`fd_close` возвращают EBADF, доступа к файловой системе/сети из WASM нет.
Память ограничена 128 MiB, файл шрифта — 4 MiB, строка — 4096 UTF-16 units,
ширина текста — 8192 px. Владельцем модуля и максимум двух шрифтов служит webview;
закрытие отменяет загрузки и освобождает шрифты/FreeType.

Единственная правка алгоритма upstream: в условие выбора `BEZIER_USE_DDA`
в `src/smooth/ftgrays.c` добавлено `ESKA_FT_NATIVE_RASTER`. Эталонный AArch64
выбирает этот же существующий DDA-путь; upstream WASM выбирал бинарное деление
кривых и давал другое покрытие. Изменения интерпретатора или коррекции пикселей
по таблице нет. ABI в `scripts/form-font-raster.c` передаёт только 32-bit offsets;
JS обновляет memory views после вызовов, способных увеличить память.

`manifest.json` связывает SHA-256 C-моста и WASM; сборка откажется использовать
устаревший артефакт. Native-тест сравнивает SHA-256 полных прямоугольных внутренних
областей 48 кнопок (275 213 RGB-пикселей) с независимыми снимками Конфигуратора.
Масок текста, допуска сглаживания или подмены эталона результатом JS нет.

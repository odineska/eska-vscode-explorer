# 1C input button atlases

Original Taxi interface assets from 1C:Enterprise web client 8.3.27.2342
(interface variant 16). The files are unchanged ZIP entries
`edtButtons_85.png`, `edtButtons_100.png`, `edtButtons_125.png`,
`edtButtons_150.png`, `edtButtons_175.png`, `edtButtons_200.png`,
`edtButtons_300.png` and `edtButtons_400.png`, from the platform-served
archive `e1csys/core83/edtButtons.zip?sysver=8.3.27.2342`.

Archive SHA-256:
`8a42b426afe5a2fb4f4dfd0eb642ab336bd6450625f1cd6796b52dba28865f50`.
The application uses the first eight cells in each strip. Cell dimensions
come from the archive's `manifest.xml`. The ninth cell is unused.

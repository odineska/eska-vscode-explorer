плитки указан в `manifest.xml` соответствующего атласа для каждой плотности.

На форме выдачи займов Linux Конфигуратор при 96 dpi подтвердил соответствие
этих плиток с максимальной ошибкой 1 на цветовой канал. «Добавить» проверено
на фоне выделения RGB(250, 204, 31), остальные — на белом фоне. В отдельной
таблице со скрытой строкой поиска тот же индекс 14 подтверждён для «Найти…».
Английский Конфигуратор использует A/Z вместо А/Я. Обе английские
плитки при 96 dpi совпали с вариантом из `core83_root.res` с ошибкой
не больше 1 на канал. Остальные плотности взяты из тех же координат
соответствующего атласа; растровая сверка выполнена только при 96 dpi.
Панель команд, динамические списки и явные картинки авторских команд
сохраняют своё оформление.

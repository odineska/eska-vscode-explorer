# Картинки перемещения строк в меню таблицы

Источник — атлас `e1csys/core/tbglacti.zip` веб-клиента 1С 8.3.27.2342.

для команд «Переместить вверх» и «Переместить вниз». Размер плитки
указан в `manifest.xml` атласа для каждой плотности.

соответствие плиток с максимальной ошибкой 1 на канал на белом фоне.

картинки сохраняют собственное изображение.
